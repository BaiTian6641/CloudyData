**Date:** 2026-10-19

**Status:** implemented_unverified — no device visual run was authorized; the
owner's physical device is not in use by this agent and the emulators were
stopped to limit laptop memory.

## Implementation

- `ChartOptions.yTickCount` is an optional persisted integer. Old documents
  load with automatic ticks; values outside 2–50 are ignored on read.
- `ChartSpecBuilder` validates the range (`ChartOptions.MIN/MAX_TICK_COUNT`) and
  carries it on `AxisSpec.tickCount` for Bar, Line and Area. Area's forced zero
  baseline copy preserves it.
- `VegaSpecBuilder` emits `tickCount` only on the continuous Y axis and pairs it
  with `labelOverlap: "greedy"` so a dense request suppresses colliding labels.
- Chart settings expose one Y tick-count field; blank means automatic, invalid
  input blocks Apply with an explicit 2–50 message. Applying settings mutates
  and persists the worksheet without rerunning SQL.
- The X axis is a Vega band scale in every current chart kind. A band axis
  ignores `tickCount`, so the nonfunctional X control was removed rather than
  shipping a control with no real operation.
