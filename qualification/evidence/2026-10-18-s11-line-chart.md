## Implemented behavior

| Area | Observed |
| --- | --- |
| Typed IR | `ChartSpec`/`ChartSeries`/`ChartPoint` carry ordered x labels, series, geometry values, exact text, `defined`, source row index, kind, title, axes, grid, legend, labels, missing policy and spec version. |
| Line query | Multi-series query groups raw x and series, selects display casts, orders by raw x then series, and requests 2001 rows to distinguish 2000 acceptable points from truncation. |
| Renderer lowering | Line marks are grouped by a Vega facet on `series`; observed NULLs use a `defined: isValid(datum.y)` signal; x domain is ordered by the semantic query’s x order; axes/legend/grid/range/log/reverse are generated from the typed spec. |
| Renderer boundary | No analytical aggregate/bin/stack/filter transform is emitted. Offline asset origin, CSP interpreter and blocked network remain unchanged. |
| Persistence | Workbook format v2 writes only nested `chart` options; v1 top-level `chartTitle/showGridlines/showValueLabels` are read and normalized, and future versions are rejected. |
| UI | Line mark, optional Color series, chart/X/Y/legend titles, Y min/max, zero/log/reverse, gridlines, value labels, legend visibility and bottom/right position. Switching to Table/Bar clears the line-only Color field. |
| Exact values | Table still shows event_date, series, Sum of value exactly: 10, 1, 20, 2, 30, 4; chart summary reports the same observed values. |
| Truncation | A truncated result is refused before drawing; no partial line is presented as complete. |
| Null/absent | Observed NULL becomes an undefined gap; absent March remains absent. No zero or synthesized March vertex. |
| Save/reopen | Force-stop/relaunch and reopen restored title, X/Y titles, 0–40 range, right legend, two series, and the exact table. |

## Fixes made after independent scout review

- Replaced a nonfunctional line `detail` usage with a real Vega series facet and
  gave the facet group an explicit width/height; without sizing, the group
  clipped all marks and the chart rendered axes only.
- Added truncation detection (`LIMIT 2001`) and refusal.
- Added nullable/undefined points and a declared observed-neighbor missing
  policy instead of throwing away a whole series on one NULL.
- Bumped workbook format to v2 and removed legacy dual-write; v1 is read,
  nested options win, future versions fail before migration.
- Removed scale clamping, rejected bar log scale, suppressed bar category
  legends, applied series-aware table/inspector labels, and capped outgoing
  renderer payloads.
- Added regression tests for null gaps, truncation/2001 boundary, bar log,
  series facet, explicit Y range, real line count in the renderer probe,
  v1/v2 document migration, future version rejection, series-column mapping,
  bar-log normalization, and chart-options undo/redo.
- Independent reviewer findings: explicit Y range was expanded by Vega's default
  zero/nice; table/inspector mislabeled a count when Color existed without
  Values; line-only log/legend settings could break bars; the line renderer test
  could pass on axes alone; the 2001 boundary and document-level v1 path were
  untested. All were fixed and covered before the final 27-test run.

## Limits

- The X axis is a categorical band over ISO date labels, not a true temporal
  scale; proportional date spacing is not claimed.
- Missing policy is declared as connect-observed-neighbors; a user-selectable
  gap/fill policy is not implemented.
- No chart mark selection, tooltip, export, facets/small multiples, dual axis,
  tick styling, line style/interpolation control or matched resize/input run.
- The line renderer caps at 2000 observed points and refuses rather than
  downsampling.
- Emulator only for this increment; physical input, TalkBack speech and physical
  window/display behavior were not re-run. The WebView exposes an ARIA summary,
  but the native summary/table remains the qualified accessible equivalent.
- Independent visual review is not yet recorded; the code review is separate.
