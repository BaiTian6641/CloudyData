# Renderer tooltip evidence

**Date:** 2026-10-18
**Requirements:** CUST12 (partial)
**Platform:** x86_64 API **36** emulator (`emulator-5580`, AVD
`Medium_Phone_API_36.1`), display override 2880×1800 at 240 dpi. The earlier
rootable API 37 emulator was ephemeral and is no longer available; this run does
not inherit its API 37 or root claims.

## Implemented path

- `ChartOptions.showTooltip` persists (default true) and appears as a Chart
  settings toggle. Old documents default to enabled.
- The Vega table now carries `exactY`; the root spec carries
  `usermeta.tooltip` so the renderer knows whether tooltips are enabled.
- A bounded `#tooltip` element (`role="status"`, max width 260 px, nowrap,
  ellipsis, pointer-events none) displays `series · x = exact value`.
- Selection (click or keyboard arrow) shows the tooltip for the selected datum.
  A Vega `cloudyHover` signal is wired to mouse hover/out events on the bar/hit
  marks and hides the tooltip on exit or on a new spec.
- The tooltip is presentation only. Renderer still has no SQL/file/network
  authority; the native summary/table remains the exact accessible surface.
- Stale charts hide the tooltip when a new spec is applied; the host still gates
  stale selection/completion messages.

| Tooltip lifecycle | New spec/selection replaces the tooltip text; selection still maps to the exact source row. |
| Show/hide option | Builder/spec test carries `tooltip=false`; persistence test saves and reopens `showTooltip=false` with default true for old documents. |
| Exactness | `exactY` is serialized from the engine value; observed NULL values render as `NULL`, not JavaScript `null`. No display rounding is introduced. |
| Coordinate conversion | SVG user-space anchors are converted with the SVG screen CTM before clamping to CSS pixels; click and keyboard placements were visually rechecked. |
| Hover | **Not verified.** `adb shell input mouse motionevent MOVE ...` did not produce a hover tooltip; `HOVER_MOVE` is rejected by this emulator's input command. Physical/pointer hover qualification remains pending. |
