  sniffer (verified by probe; if inferred otherwise, an explicit text override
  is required before Q01 can pass). `name` row 1 is `Alpha, Inc.`; row 2 is
  `Quote "inside"`. `note` row 1 contains an embedded newline. Empty `note`
  becomes NULL under DuckDB's default empty-string policy.
- Duplicate headers: DuckDB auto-renames duplicates; the imported field names
  must be surfaced without silent loss. Exact names are recorded by the probe.
- Q02: BIGINT `9007199254740993` survives as Int64. Decimal `0.10 + 0.20` is
  exactly `0.30`; it must never pass through Double on the display/transport
  path. Timestamp microsecond `12:34:56.123456` survives. Unicode `héllo 世界 🚀`
  and quotes/apostrophes survive byte-for-byte.
